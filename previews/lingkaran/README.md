Static preview site for Lingkaran. Source of the screens: the "Lingkaran Redesign Preview" artifact, cleaned (internal notes removed, sample data only). Deployed as the Vercel project `lingkaran-preview` from the branch `lingkaran-preview-site`, which holds a copy of these files at its root.

Tour layout: one group is shown at a time (tabs), 6 screens first, 12 more per click. Without JavaScript every screen is shown. Only the tab script at the end of index.html is JavaScript.
